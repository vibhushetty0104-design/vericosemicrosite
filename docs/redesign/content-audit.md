# Meridian Vascular — site-wide content audit and canonical content map

> Status: **proposal, awaiting owner review (2026-10-21).** Nothing in this document has been
> implemented. No clinical content has been changed or reviewed. Every "merge" or "remove" below
> moves or summarises content; essential warnings are never removed.

## 1. How this was audited

- Source read for all 38 components, `src/data/*` and `src/utils/clinicalGuidance.ts` at the end of
  Milestone 2 (branch `chore/claude-skill-toolkit`, uncommitted work included).
- A topic × component matrix was generated by pattern search (for example reflux thresholds, valves,
  DVT, CEAP, treatments, insurance), then every overlap listed below was confirmed by reading the
  component text. Raw counts are indicative only (for example "Book" also matches icon imports).
- Views audited: home, `#learn`, `#journey`, `#assessment`, `#doppler`, `#treatments`,
  `#specialists`, `#dashboard`, the menu sheet, the footer, the guide panel and the request modal.

### 2.4 Repeated calls to action

- **Request an appointment (demo):** header, menu, footer (twice), home find-care section (plus one
  per card), Doppler decoder (several), treatment comparison (several), care pathway, portal, guide
  answers, symptom-check result and photo section. Proposal: global entry points stay (header,
  menu, footer); in content, one request action per view at the natural decision point (end of the
  comparison, the symptom-check result, the directory).
- **Ask the guide:** a contextual button in most sections of `#learn`, the FAQ and tools.
  Proposal: keep contextual "Ask the guide about this" only where a pre-written answer exists for
  that topic (checked against `GUIDE_SUPPORTED_TOPICS`); otherwise rely on the header/menu entry.
- **Symptom check:** promoted from the hero, home tiles, menu, footer, care pathway, Learn sections
  (`Causes`, `Symptoms`, `LegPainDifferential`, `ProgressionCEAP`, `DvtAndMisconceptions`) and the
  portal. Proposal: hero, menu, footer and the end of *Symptoms* only.
